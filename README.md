# GTech Digital

The website and admin panel are one Laravel app in **[`backend/`](backend/README.md)**: the public site (Blade
templates), the admin panel at `/admin`, lead CRM, page builder, analytics and the API.

- **Try it on Windows:** install Laravel Herd, then double-click `backend/start-windows.bat`.
- **Install on a server, Cloudflare, data import from MongoDB:** see [backend/README.md](backend/README.md).

The earlier Next.js version of the site was removed from this branch; it is still in the Git history.
